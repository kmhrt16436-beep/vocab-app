# 忘却曲線による単語の復習

「学習する」画面の「復習の方式」で、忘却曲線による個別調整と従来の固定間隔を切り替えられます。

## 忘却曲線モード（初期設定）

- 新規カードは当日から出題し、初めて○になったカードは翌日に復習します。
- ○を重ねると、その単語の推定記憶の強さに応じて復習間隔が伸びます。
- ×は間隔を翌日に戻し、当日の通常出題の最後に1回だけ再出題します。
- 同じ日の再出題で○になっても間隔を伸ばさず、翌日も復習します。
- 間隔は最短1日・最長60日です。
- 出題順の初期設定はランダムです。今日の対象となる新規・復習カードを混ぜて出題し、×のカードの再出題は最後にまとめます。復習日の計算は変えません。
- ○の条件は①②の意味をすべて言えた場合のみです。

## 推定の方法と限界

記憶度の減衰には `R(t) = 0.9^(t/S)` を使用します。`t` は前回の復習からの経過日数、`S` は推定記憶度が90%になるまでの日数です。通常の出題の○でSを増やし、×でSを下げます。単語ごとの難易度も○・×から調整します。

これは学習履歴に基づく目安で、実測の正答率ではありません。個人の学習データで検証・最適化したFSRSモデルではありません。同日中の解き直しを、長期間覚えていた証拠として扱わないようにしています。

## 既存カードと固定間隔

既存のカードID・内容・次回復習日・今日の残り枚数を引き継ぎます。以前の履歴がないカードは、従来の段階と予定日から初期の記憶の強さを推定します。以後の判定で履歴を蓄積します。

固定間隔モードは `0 → 1 → 3 → 7 → 14 → 30 → 60日` を維持します。方式を切り替えた時点で既存の予定日は変更せず、次の判定から適用します。

## PC・スマホで使う場合

更新後はPCとスマホの両方でアプリを再読み込みし、同じアカウントにログインしてから学習してください。データは自動で同期します。「データ」の同期表示が「同期済み」になることを確認します。

記憶度と判定履歴、復習方式は、カードと一緒にクラウド同期・JSONエクスポートの対象になります。

現在の保存形式はversion 4です。旧version 1〜3のJSONも読み込めます。出題順が未設定の既存データはランダムを初期値にし、カードの内容・学習履歴・復習日は維持します。両方の端末でアプリを再読み込みしてください。

## 出題順と画像の表示

「データ」→「復習の設定」（PCでは左側）で、出題順を「ランダム」「忘れやすい順」から選べます。「出題順を混ぜる」で、今日の未回答カードを再度シャッフルできます。

ランダムな順番は端末・ページごとに作り、表示中の同期や再描画では保ちます。ページを開き直す、日付が変わる、手動で混ぜる場合は新しい順番になります。PC・スマホで順番が違っても、回答結果・復習日・タグによる共有は共通です。学習済みのカードや復習日がまだ先のカードを、シャッフルによって追加しません。

画像付きカードは表示領域を広げています。スマホでは①②の答えを先に表示し、③〜⑤は「関連・例文・補足を見る」で開閉します。画像は全体が見えるように表示し、タップすると拡大できます。PCでは画像を広い右側に置き、関連事項や例文も最初から開いて表示します。データや画像そのものは変更しません。
