# 忘却曲線による単語の復習

「学習する」画面の「復習の方式」で、忘却曲線による個別調整と従来の固定間隔を切り替えられます。

## 忘却曲線モード（初期設定）

- 新規カードは当日から出題し、初めて○になったカードは翌日に復習します。
- ○を重ねると、その単語の推定記憶の強さに応じて復習間隔が伸びます。
- ×は間隔を翌日に戻し、当日の通常出題の最後に1回だけ再出題します。
- 同じ日の再出題で○になっても間隔を伸ばさず、翌日も復習します。
- 間隔は最短1日・最長60日です。
- 期限が来たカードの中で、推定記憶度が低いカードを先に出します。新規カードは履歴のある復習カードの後、当日再出題の前に出します。
- ○の条件は①②の意味をすべて言えた場合のみです。

## 推定の方法と限界

記憶度の減衰には `R(t) = 0.9^(t/S)` を使用します。`t` は前回の復習からの経過日数、`S` は推定記憶度が90%になるまでの日数です。通常の出題の○でSを増やし、×でSを下げます。単語ごとの難易度も○・×から調整します。

これは学習履歴に基づく目安で、実測の正答率ではありません。個人の学習データで検証・最適化したFSRSモデルではありません。同日中の解き直しを、長期間覚えていた証拠として扱わないようにしています。

## 既存カードと固定間隔

既存のカードID・内容・次回復習日・今日の残り枚数を引き継ぎます。以前の履歴がないカードは、従来の段階と予定日から初期の記憶の強さを推定します。以後の判定で履歴を蓄積します。

固定間隔モードは `0 → 1 → 3 → 7 → 14 → 30 → 60日` を維持します。方式を切り替えた時点で既存の予定日は変更せず、次の判定から適用します。

## PC・スマホで使う場合

更新後はPCとスマホの両方でアプリを再読み込みし、同じアカウントのクラウドデータを読み込んでから学習してください。「データ」の同期表示が「同期済み」になることを確認します。

記憶度と判定履歴、復習方式は、カードと一緒にクラウド同期・JSONエクスポートの対象になります。

保存形式をversion 2に更新し、旧version 1のJSONは読み込み時に移行します。古いアプリが新しい履歴を削って上書きしないよう、両方の端末を最新版に更新してください。画像だけの更新ツールもversion 2に対応しています。
