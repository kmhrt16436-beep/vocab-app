# ホーム画面からアプリとして使う（PWA）

AndroidのChromeで公開URLを開き、右上の「⋮」→「ホーム画面に追加」→「インストール」を選びます。インストール候補として認識されると、「データ」→「アプリとして使う」の「アプリをインストール」からも追加できます。Chromeのバージョンによってはメニューに「アプリをインストール」と表示されます。

同じChrome・同じプロファイルからインストールした場合、URLと保存先は変わらず、既存のカード・フォルダ・学習履歴・ログインを引き継ぎます。アプリを開いて同じメールアドレスでログインすれば、これまでと同じようにほかの端末とも同期します。別のブラウザや別プロファイル、シークレットモードの保存領域は共有しません。

一度オンラインで開き、Service Workerの準備が完了すると、保存済みカードは通信なしで学習・再起動できます。学習結果は端末へ保存し、アプリを開いて通信が戻ると既存の同期処理で送信します。画像はこのサイト内のTOEIC画像で、表示済みの直近32枚までをキャッシュします。外部URLの画像や未表示の画像には通信が必要です。ブラウザが空き容量の確保でキャッシュを削除した場合も、再度オンラインで開いて準備する必要があります。

新しいService Workerが準備された場合は、「データ」→「アプリとして使う」に更新ボタンを表示します。学習中に勝手に再読み込みしません。オンラインでページを再読み込みした場合は最新のHTMLを優先します。

インストールは無料で、Google Playを経由する必要はありません。Google PlayやApp Storeでの配布を希望する場合は、別途ストア向けのパッケージ・開発者登録・審査が必要です。

## 公開に必要なファイル

通常のブラウザ利用は従来どおり`index.html`から利用できます。PWAとしてのインストールとオフライン起動には、次のファイルを相対パスを保って公開してください。GitHub Pagesでは追加設定やビルドは不要です。

```text
index.html
manifest.webmanifest
service-worker.js
icons/icon-192.png
icons/icon-512.png
```

Service Workerの範囲はこのアプリのディレクトリのみです。キャッシュするのは静的HTML・マニフェスト・アイコンと画像だけで、Supabaseの認証・API応答をキャッシュしません。個人のカード・進捗と認証状態の保存先は既存のlocalStorageです。

検証は`python tests/test_pwa.py`で実行します。PythonのPlaywrightとChromiumが必要です。ローカルHTTPサーバーを起動し、実際のService Workerでオフライン再読み込み、カード判定と履歴の保持、画像キャッシュの上限、APIをキャッシュしないこと、インストールボタン、手動更新を確認します。実アカウントには接続しません。
