# 英単語の10語コラム

英単語フォルダに「コラム」を追加しました。熱・空気などの「その他の学習」フォルダには表示しません。「すべてのフォルダ」では英単語カードだけが対象です。タグを選ぶと、そのタグの英単語でページを作ります。

## 読み方

同じ日に異なる英単語を10枚解答すると、読むか学習を続けるかの案内が出ます。○・×のどちらも1語として数え、同じカードの繰り返しや×の再出題は加算しません。コラムを読んでもカードの復習予定・正解数・キューは変わりません。スマホでは下の「コラム」、PCでは左の「コラム」から、いつでも読み返せます。

ページは10語ごとにまとめ、最後の1〜9語にも1ページを用意します。出題がランダムでも、ページのまとまりは変わりません。フォルダ・タグ・カードの増減に応じてページを組み直します。10語の区切りでは、今回学習した語と重なるページからおすすめします。

## 内容

配布126項目には、元の順で10語ずつ、最後は6語の計13本があります。各ページは比較表、3つの解説と例文・和訳、3択確認問題、要点で構成しています。

1. 位置・移動・放置と前置詞
2. 山積みの状態と手伝いの申し出
3. almost、予定の前後、reportの語法
4. restore・renovate・remodel・refurbish
5. 推量・助言・eitherの応答
6. 丁寧な依頼とmindへの応答
7. 担当・職・作業とlet／allow
8. seat／sit、find／find out、would rather
9. 案内文と電話の保留・転送
10. 移動案内、go on、pass on
11. 感謝・謝罪・処罰とlaunch／roll out／implement
12. 予定、順序、配管・水害の語彙
13. sink・drain・sewer・sewage

初期サンプル5語にも専用解説があります。未収録の新しい単語のまとまりには、品詞・修飾や時間の前置詞についての共通コラムを割り当てます。新しい単語の意味や専門的な比較をAIが自動生成する仕組みではありません。TOEICの目標学習用に自作した解説・例文であり、公式問題の転載や得点の保証ではありません。

本文はアプリに埋め込まれているため、通信や追加のAPIキーは不要です。アプリのオフライン準備後はコラムも読めます。10語の案内カウンターは端末・アカウント・日付ごとに端末内へ保存し、カードのクラウドデータには加えません。既存のカード、CSV、JSON形式を変更せず使えます。

## 本文の編集・確認

`study/english/columns.json` を編集し、次のコマンドでHTMLへ埋め込みます。

```sh
python tools/build_english_columns.py
python tests/test_english_columns.py
```

テストは配布126語と13ページの対応、確認問題、英語限定表示、10語の案内、再出題の除外、読み飛ばし、履歴保持、アカウント分離、スマホ・PC表示を確認します。
