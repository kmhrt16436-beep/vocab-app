# PCで登録、スマホで学習する自動同期

同じSupabaseプロジェクトと同じメールアドレスでログインすると、保存先の選択なしで同期します。既存の接続設定とログイン情報は引き継ぎます。

## 普段の使い方

1. PCで単語カードを追加、またはCSVを追加します。
2. 約1秒後に自動送信します。上部の「同期済み」を確認してからPCのページを閉じます。
3. スマホでアプリを開くと、追加されたカードを自動で読み込みます。
4. スマホでの○・×と次回の復習予定も自動保存します。

画面を開いている間は約20秒ごと、画面に戻ったとき、ネット接続が戻ったときにも同期します。ログイン状態が残っていれば、ページを開き直しても自動で再開します。ブラウザが終了・停止中の端末から送信し続ける機能ではありません。

ログインが切れた場合のみメールから再ログインしてください。異なるSupabaseプロジェクトやメールアドレスには同期しません。

## 更新の合わせ方

- 新しいカードを追加し、既存カードの学習進捗を合わせます。
- 端末に最後に保存したクラウドの状態を基準に、片方で行った編集・削除・学習結果を反映します。
- 一方で削除したカードを、古い端末のコピーから復活させないようにしています。
- 同じカードの履歴はひとまとまりで扱います。両端末で同時に学習した場合は、新しい日付・多い判定回数を優先し、同日・同数で異なる場合は間隔の短い方を優先します。
- 同じ項目を両端末で同時に編集した場合はクラウド側の値を優先します。登録・編集は普段使うPCにまとめると分かりやすく使えます。
- 保存直前に他端末が更新した場合は版番号を照合して再試行します。

## 通信が切れた場合

変更は端末に残し、「未同期」と表示します。同じブラウザでアプリを開いたまま再接続するか、後から開き直すと送信を再試行します。

## 復旧用

自動同期へ移行する前の端末データを、ブラウザ内に保存します。「データ」→「復旧用の操作」→「同期前の端末データをJSONで保存」から取り出せます。普段は使う必要はありません。

全データの読み直し・置き換えは「復旧用の操作」に残しています。通常のカード追加や学習では操作不要です。

この更新を使い始めるときは、PC・スマホの両方でアプリを再読み込みしてください。忘却曲線の記憶度、カード、復習日を含む保存形式はversion 2のままです。SupabaseのSQLやメール設定を変更する必要はありません。
