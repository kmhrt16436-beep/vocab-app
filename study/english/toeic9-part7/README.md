# 公式問題集9 Part 7 · 画像付き145語

利用者が記録した146項目から、重複する extensive を1枚にまとめました。①は利用者の指定した意味を優先します。公式問題の文章・問題画像は使わず、例文・和訳・関連語・イラストは独自に用意しています。

## 追加

[追加用リンク](https://kmhrt16436-beep.github.io/vocab-app/index.html?pack=toeic9-part7)を、いつものアプリと同じブラウザで一度開きます。「公式問題集9」タグで英単語フォルダに追加し、ログイン済みなら通常の自動同期で他端末にも反映します。通常のアプリ閲覧だけでは登録されません。

同じ語があればカードと復習履歴を引き継ぎ、今回の意味を①に、以前の①を必要に応じて②に残します。以前のタグ・復習予定・直接追加した写真は保持します。その他の既存カードのタグは変えません。追加前の画像入りJSONバックアップは、追加画面のボタンで保存できます。登録済みカードを編集した後に同じ追加リンクを開いても、その編集内容は上書きせず、カードを増やしません。

[画像一覧](illustrations.html) · [7列CSV](cards.csv)。CSVは手動取り込み用の別の方法です。追加用リンクを使った後に、同じCSVを重ねて取り込む必要はありません。

## 画像の形式

4つの具体的な場面を一度に生成し、各カードはSVGの独立した表示領域を参照します。PNGの画素・文字・構図には変更を加えません。`sheet-NN.svg#card-N` はその語の場面だけを表示します。文字は英語です。アプリ内拡大でも同じ場面を表示します。画像URLの利用には通信が必要です。

本文は `cards.json`、7列形式は `cards.csv`、画像の対応は `image-catalog.json`。生成画像からの表示領域の構築は `tools/build_toeic9_images.py`、追加処理は `tools/toeic9_pack_runtime.js`、アプリへの組み込みは `tools/install_toeic9_runtime.py`。検証は `tests/test_toeic9_pack.py` です。
