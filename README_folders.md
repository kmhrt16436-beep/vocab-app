# 教科別のフォルダ

画面上部のフォルダ名で学習対象を切り替えます。「すべてのフォルダ」を選ぶと教科をまとめて復習できます。フォルダの選択は端末ごとに記憶し、ほかの端末の表示を切り替えません。

1. フォルダ名の右の「管理」を押す。
2. フォルダ名とカードの種類を選び、「フォルダを作る」を押す。
3. 「カード管理」で追加するか、「データ」のCSV追加で追加先を選ぶ。

英単語用は従来の7項目です。「その他の学習」は、問題・用語、①重要な答え、②補足・別の答え、③関連事項、④例・解説、⑤補足説明、⑥図・イラストの7項目になります。必須項目は表面と①だけです。CSVもこの順の7列です。①と②をすべて言えた場合だけ○にする判定方法、画像URLの表示、忘却曲線による復習は共通です。

カードの編集画面の「保存先フォルダ」を変えると、復習予定と履歴を保持して移動できます。管理画面では名前の変更と削除もできます。最初のフォルダは削除できません。それ以外のフォルダを削除した場合は、中のカードを最初のフォルダへ移します。

既存データは自動で「英語」に移行します。カードのID・画像・次回復習日・履歴は変更しません。JSONバックアップにはフォルダも含み、従来のバージョン1・2のバックアップも読み込めます。フォルダ対応後の保存形式はバージョン3です。画像URLだけを更新する補助ページもバージョン3に対応しています。

同じメールアドレスでログインしていればフォルダとカードを自動同期します。Supabaseの設定変更は不要です。更新後はPCとスマホの両方でページを再読み込みしてください。以前のアプリはバージョン3のデータを読めないため、再読み込みが必要です。

## 検証

PythonのPlaywrightとChromiumを使います（アプリ自体に追加ライブラリは不要です）。通信先はすべてテスト用に差し替え、実アカウントや実データは使いません。

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/test_folders_ui.py
python tests/test_folders_sync.py
```

システムのChromiumも使用でき、`CHROMIUM_PATH`で実行ファイルを指定できます。UIテストは旧データ移行、作成・名前変更・削除、他教科の入力欄、フォルダ別出題と再出題、CSV追加、カード移動、JSON復元を確認します。同期テストはフォルダの同時追加、名前変更と学習、移動と学習、削除とオフライン追加の競合、フォルダ別の進捗、既存の自動同期とアカウント分離を確認します。
