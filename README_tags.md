# タグと共有カード

1枚のカードに「熱」「2020年過去問」「重点復習」など複数のタグを付けられます。どのタグ・フォルダから開いても復習履歴と次回復習日は共通です。通常はその日のキューに1回だけ入り、×の場合だけ最後に1回再出題します。

## 使い方

- **カード編集**：「タグ」にカンマ・読点で区切って入力します。タグ名は1〜60文字です。
- **CSV取り込み**：「取り込むカードのタグ」に入力すると、そのCSVの全カードへ付きます。CSV本体は従来の7列のままです。
- **既存カードへまとめて追加**：「カード管理」→「表示中のカードにタグを付ける」。現在のフォルダ・タグ・検索条件で表示されるカードが対象です。
- **タグ別学習**：画面上部のタグ欄で絞り込みます。フォルダとタグは組み合わせて使えます。複数のフォルダを横断するときは「すべてのフォルダ」を選んでください。
- **名前変更・取り外し**：上部の「タグ」から管理します。タグを外してもカードと復習履歴は削除しません。

## 同じカードの取り込み

同じ種類（英単語／その他の学習）で、表面・①〜⑤の内容が一致するカードを共有します。前後の空白と改行コードの違いは吸収します。授業図の新旧URLの違いも吸収します。それ以外の独自画像が異なる場合や、答え・補足が違う場合は、別のカードとして残します。

同じカードを別のデータセットのCSVから追加すると、カードは増やさずタグ・追加先フォルダを共有します。既存の復習予定を維持し、新規カードとしてキューへ入れ直しません。表示された「新規○枚、既存カードと共有○枚」で確認できます。

以前からある重複カードも、読み込み時に自動で共有します。元のフォルダ名をタグに残し、元の各フォルダからも1枚の共有カードを開けます。複数の履歴は直近の復習を優先し、同日なら判定回数などで選びます。別々のコピーの回数を足し合わせて架空の履歴にはしません。すでに今日答えたコピーがある場合、未学習コピーから同じ問題を再出題しません。

カード自体を削除すると、共有する全フォルダ・タグから削除します。フォルダの削除ではカードを残し、ほかの共有先または最初のフォルダへ引き継ぎます。

## 保存と同期

タグ、共有先、統合元のID、カードごとの今日の判定回数をJSONへ保存します。保存形式はversion 4です。version 1〜3のJSONも読み込めます。タグと学習履歴は同じメールアドレスで自動同期し、異なるタグの同時追加や、PCでのタグ編集とスマホでの復習を合わせます。同じタグについて追加・削除が競合した場合は、最後に共有した状態を基準に削除を反映します。

更新後はPC・スマホの両方で再読み込みしてください。Supabaseの設定変更は不要です。

旧データを初めて読み込む際、タグ移行前のJSONをアカウントごとにブラウザへ保存します。「タグ」→「タグ対応前のデータをJSONで保存」から取り出せます。今の状態は通常のJSONエクスポートで保存できます。

```sh
python tests/test_tags.py

python tests/test_folders_sync.py

```

Playwright＋Chromiumで、旧データの重複統合、七列CSV、複数タグとフォルダでの学習・再出題・共有履歴、タグ操作、JSON復元、同時取り込みと端末間同期、オフライン保存、スマホとPCのレイアウトを確認します。実際のアカウントのカード・クラウドデータはテストに使いません。

## 熱・空気セットの自動分類

登録済みの総復習298枚と、今後七列CSVから追加する同じカードを自動分類します。

- 熱分野：142枚。
- 空気分野：156枚。
- テスト用：218枚。従来の過去問重点版と同じ、過去問直結の内容＋解法に必要な基礎です。分野タグと重複します。

先行5枚にも対応します。元セットの問題文と照合し、該当カードのタグだけ追加します。独自タグ、本文、画像、フォルダ、復習日、学習履歴、キューを保持します。一度適用したカードの適用履歴をJSONとクラウドに保存するため、後から外したタグを再読み込みのたびに付け直しません。再読み込み時に自動で適用し、クラウドにも自動保存します。CSVの再登録は不要です。

分類の元データは `study/heat-air/complete/cards.json`、再生成は `python tools/apply_heat_air_tags.py`、検証は `python tests/test_heat_air_tags.py` です。
