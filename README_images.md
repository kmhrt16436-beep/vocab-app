# 英語イラスト126枚

画像は `toeic-001.png` から `toeic-126.png` です。画像内のラベルは英語です。

[画像付きCSVをダウンロード](https://kmhrt16436-beep.github.io/vocab-app/TOEIC_images.csv)

## 新しくカードを登録する場合

CSVの内容をアプリの「データ」→「CSVを貼り付け」に貼り付けて追加します。

## すでに126項目を登録済みの場合

CSVを追加すると重複カードが作られるため、画像だけの更新がおすすめです。

1. アプリでJSONをエクスポートします。クラウド同期を使っている場合は、目的のアカウントのデータを同期してから保存します。
2. [画像だけの更新ツール](https://kmhrt16436-beep.github.io/vocab-app/update-existing-cards.html)を開きます。
3. JSONを選び、画像更新済みJSONを保存します。元のバックアップも残してください。
4. アプリで更新済みJSONを復元します。

ツールは126項目の英単語と完全一致するカードの⑥だけを変更します。カードID・意味・例文・学習進捗は保持します。ファイルは外部送信しません。

以前から同じ画像URLを使っているカードは、画像の上書きだけで更新されます。
