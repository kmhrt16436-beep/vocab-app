## 類義語・派生語・対義語の品詞

③は `派）名）restoration：修復`、`類）動）buy：買う`、`類）形）obtainable：入手可能な` の形式です。名・動・形・副・前・接・代を使えます。熟語・フレーズには品詞を付けません。

配布126枚中83枚と初期サンプルの関連語について、単語と日本語の意味を確認した130組をアプリに収録しました。既存カード・CSV・JSON・クラウドの読み込み時に③へ品詞を補います。再インポートは不要です。画像・例文・タグ・復習予定・履歴は維持し、変更があれば自動同期します。以前のCSVと更新後のCSVは、③の表記差だけでは重複しません。

補記は英単語フォルダに適用します。入力済みの品詞、熟語・フレーズ、未知の語義、自分のメモは保持します。新しい単語の品詞をつづりから推測する機能はないため、収録されていない関連語は品詞も入力してください。

## 新しくカードを登録する場合

CSVの内容をアプリの「データ」→「CSVを貼り付け」に貼り付けて追加します。

## すでに126項目を登録済みの場合

CSVを追加すると重複カードが作られるため、画像だけの更新がおすすめです。

1. アプリでJSONをエクスポートします。クラウド同期を使っている場合は、目的のアカウントのデータを同期してから保存します。
2. [画像だけの更新ツール](https://kmhrt16436-beep.github.io/vocab-app/update-existing-cards.html)を開きます。
3. JSONを選び、画像更新済みJSONを保存します。元のバックアップも残してください。
4. アプリで更新済みJSONを復元します。

ツールは126項目の英単語と完全一致するカードの⑥だけを変更します。カードID・意味・例文・学習進捗は保持します。ファイルは外部送信しません。

以前から同じ画像URLを使っているカードは、画像の上書きだけで更新されます。
