# 写真・画像ファイルの追加とトリミング

アプリをPC・スマホの両方で再読み込みしてから使ってください。追加サービスの設定やSupabaseのSQL変更は不要です。

## 使い方

1. 「カード管理」でカードを追加、または編集します。
2. ⑥の「画像を選ぶ」で写真・スクリーンショットを選びます。PCでは画像の貼り付け、ドラッグ＆ドロップも使えます。
3. 切り抜き枠をドラッグして移動し、四隅を動かしてサイズを変えます。枠の外をドラッグすると範囲を描き直せます。
4. 必要に応じて「90°回転」「全体に戻す」「数値で調整」を使います。
5. 「この範囲を使う」でプレビューを確認し、最後にカードの「保存する」を押します。

スマホでは指で操作できます。キーボードでは枠をフォーカスして矢印キーで移動し、四隅のボタンをフォーカスして矢印キーでサイズを調整できます。Shift＋矢印は細かい調整です。

「画像を貼り付け」はブラウザの許可・対応状況によります。使えない場合は編集画面でCtrl＋V／貼り付けを行うか、画像ファイルを選んでください。

カードを保存する前なら「切り抜きを調整」で元の選択画像からやり直せます。保存後は切り抜き済みの画像を元に再調整します。切り落とした部分を戻したいときは、元の写真をもう一度選んでください。元の写真全体は自動保存しません。

PNG・JPEG・WebP・GIF・BMPに対応します。GIFは静止画として取り込みます。入力は25MB・6000万画素以下。読み込み時に長辺最大3200px、保存時に長辺最大1600px・160KB以下へ軽量化します。通常はWebPを使い、未対応のブラウザではPNG/JPEGに切り替えます。JPEGに変換する場合は透明部分が白になります。画像を描き直して保存するため、元ファイルの位置情報・EXIFは含めません。

## 保存・同期・バックアップ

- 追加画像はブラウザのIndexedDBへ保存し、カードと進捗のlocalStorageには小さな参照だけを残します。写真データでlocalStorageを埋めない構成です。
- 同期を使う場合は、同じメールアドレスでログインしてから追加してください。既存のアカウント別保存先へ、画像本体もカードと一緒に自動送信します。別の端末では画像を端末内へ復元します。
- 更新がないかの定期確認では版番号だけを取得します。変更がある場合にカード・画像を読み込みます。「今すぐ同期」は画像本体も再取得するため、端末内の画像が失われたときにも使えます。
- JSONエクスポートには追加画像の本体を含めます。画像入りJSONは、元の端末の保存領域がない別ブラウザにも復元できます。
- PWAをオンラインで準備した後は、保存した追加画像をオフラインでも表示できます。画像の同期・メールログインには通信が必要です。
- 画像は公開GitHubリポジトリや公開画像URLへアップロードしません。端末の画像保存領域もアカウントごとに区別します。ログイン前のデータは従来どおり別の端末データとして残します。

ブラウザのサイトデータを消去すると、未同期・未バックアップの画像も失われます。機種変更や保存領域の削除前には画像入りJSONを保存してください。

現在のクラウド保存は既存の全データ更新に画像を含めるため、画像が多くなるほど保存時の通信量・同期時間が増えます。多数の画像を扱う商用運用では、専用の非公開画像ストレージと容量・料金管理への移行が必要です。

外部の画像URLも従来どおり使えます。外部サイトが画像の取得を許可しない場合、URLから直接切り抜けないことがあります。その場合は画像ファイルを端末へ保存してから追加してください。

python tests/test_image_upload_crop.py

python tests/test_tags.py

Playwright＋Chromiumを使用します。切り抜いた領域の画素、画像の永続保存、画像入りJSONの別ブラウザへの復元、タッチ移動・回転、カメラ写真の向き、貼り付け・ドロップ、同期、アカウント分離、オフライン表示を検証します。実アカウントや個人の写真は使用しません。
